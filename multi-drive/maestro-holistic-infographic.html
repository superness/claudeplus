🎭 Maestro: Complete AI Orchestration

An open-source framework for recursive AI agent workflows

Unlike simple prompt chaining, Maestro coordinates multiple specialized AI agents through structured phases

1 Plan
Pipeline Planning Strategy: Pipeline

Every task starts with structured planning. An AI expert agent reviews the plan—if gaps exist, it loops back for refinement until the approach is solid. Example: "Build a REST API"

Task → Planner → Expert Review →
⟲ Loop until approved
→ ✓ Approved Plan
2 Route
ABUDDI Decomposition Strategy: Complexity Scoring

Product Maestro evaluates complexity using 6 dimensions. Complex tasks get delegated to Feature Owners (specialized AI agents), who recursively decompose until work becomes atomic (fits in one context).

ABUDDI = Atomic scope Breadth Uncertainty Dependencies Depth Impact
Score Task → 0-60 pts → Delegate? → Feature Owner 1 Feature Owner 2 Feature Owner 3

→ 4 Feature Owners work in parallel on different API endpoints

3 Execute
Contextual Agent Chats Strategy: Context Preservation

Each agent has a dedicated chat tab with persistent context. Hats inject domain expertise (code patterns, project docs). Follow-ups and bug fixes happen in-context without re-explaining.

🎩 Hat = injected system prompt + relevant documentation for that agent's domain
Agent Tab → 🎩 Hat Context → Execute → Iterate → ✓ Done

→ "Fix the auth bug" in the same tab that built auth—full context preserved
