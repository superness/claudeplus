Multi-Drive Maestro
Welcome to Multi-Drive Maestro - the recursive AI orchestration system.

How It Works:
• Every request is evaluated using ABUDDI complexity scoring
• Complex tasks are recursively decomposed into subtasks
• Each subtask is handled by a specialized agent (Feature Owner, Sub-IC)
• Results flow back up and are synthesized into a final response

ABUDDI Dimensions:
• Atomic scope - files to read/modify
• Breadth - domains of expertise required
• Uncertainty - unknowns to resolve
• Dependencies - integration points
• Depth - layers deep
• Impact - blast radius of changes

Agent Hierarchy:
🎭 Product Maestro → 👔 Feature Owner → 👷 Sub-IC
